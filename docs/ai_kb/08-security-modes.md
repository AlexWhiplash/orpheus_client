# Безопасность в приложении (PIN / Duress / Wipe)

Ниже — пользовательское описание режимов безопасности: что они делают и где находятся.

## Где включать
Откройте вкладку **Профиль** → **Безопасность**.

## PIN‑код (блокировка приложения)
- Если PIN **не задан** — вход в приложение открыт.
- Если PIN **включён** — приложение может блокироваться при запуске и/или при сворачивании (в зависимости от настроек).

## Duress‑код (код принуждения)
Это “второй PIN”, который открывает приложение в **режиме правдоподобного отрицания**.
Что происходит при входе по duress‑коду:
- профиль выглядит пустым: нет контактов, переписки, заметок, журнала звонков;
- **комнаты и «Чат с разработчиком» тоже пустые** — они хранятся на сервере, и в этом
  режиме приложение к ним не обращается;
- экраны, открытые ДО блокировки (например чат), закрываются — вернуться к ним из
  duress‑сессии нельзя;
- экран **«Безопасность» показывает duress‑ и wipe‑код как не настроенные**, поэтому по
  нему нельзя понять, что такие коды вообще заданы;
- настройки безопасности в этом режиме **не изменяются** (auto‑wipe, «жест паники»,
  биометрия, таймер блокировки, срок хранения сообщений, имя звонящего на локскрине) —
  чтобы никто не смог заранее снять ваши защиты;
- реальные сохранённые данные duress‑режим **не удаляет**: они просто недоступны в
  интерфейсе. Ввод настоящего PIN возвращает обычный профиль.

**Чего duress‑режим НЕ делает (знать заранее):**
- **уведомления продолжают приходить.** Они обезличены (без отправителя и текста), но сам
  факт уведомления на экране виден;
- **сообщения, полученные во время duress‑сессии, не сохраняются** — после выхода из
  режима их не будет, хотя у отправителя они выглядят отправленными;
- это **не стирание данных**: настоящий PIN всё возвращает.

## Код удаления (Panic wipe code)
Отдельный код для **полного удаления данных на устройстве**; после ввода требуется
подтверждение удержанием кнопки.

⚠️ **Важно:** в текущих версиях подтверждение с экрана блокировки может не открываться,
поэтому **не полагайтесь на wipe‑код как на единственный способ** экстренного стирания.
Надёжно работающие пути — **Auto‑wipe** (стирание после N неверных попыток PIN, см. ниже)
и «жест» panic wipe. Мы это исправляем.

## Auto‑wipe (удаление после N неверных попыток)
Опция: удалить данные после заданного числа неверных попыток ввода PIN.
Включайте только если понимаете риск необратимой потери данных (ошибка ввода/дети/случайные касания).

## “Жест” panic wipe
Опция (по умолчанию может быть выключена): несколько быстрых уходов приложения в фон → wipe.
Это сделано для экстренных ситуаций; путь рабочий, но случайное срабатывание тоже возможно.

## Экспорт аккаунта (приватный ключ) — очень важно
Вкладка **Профиль** → **Экспорт аккаунта** показывает приватный ключ.
Доступ защищён биометрией (отпечаток/лицо); если биометрия недоступна — PIN‑кодом
приложения. В **duress‑режиме** экспорт требует именно **PIN приложения**: системный
код‑пароль устройства и duress‑код не принимаются.

Приватный ключ = полный доступ к аккаунту.
- Не отправляйте его никому (в том числе “в поддержку”).
- Храните только в безопасном месте.

## Защита от скриншотов/записи экрана
На Android приложение включает защиту от скриншотов/записи экрана для приватности.
Для обмена ID используйте “Поделиться контактом” или копирование ключа, а не скриншоты.
